Exam Flow 운영설정

🏢 관리실

백업·템플릿·초기화를 관리합니다. 입력 내용은 이 PC에 자동 저장됩니다.

🗂️ 데이터 관리

왼쪽 사이드바의 저장·불러오기로 작업을 관리할 수 있습니다. 아래는 템플릿·백업·초기화입니다.

설정 템플릿

시험 규칙·고사실 설정만 저장합니다. 학생 데이터는 포함되지 않습니다.

운영 백업

학생 데이터를 포함한 전체 운영 상태를 백업합니다.

JSON 백업

데이터 초기화

모든 데이터와 저장된 작업을 삭제합니다. 되돌릴 수 없습니다.

⚙️ 운영설정

학교·시험 기본 정보, 시간표, 이동 방식, 좌석·고사실을 설정합니다.

🏫 학교 정보

출력물 상단에 학교명이 표시됩니다. 학년도·학기는 아래 시험 기본 정보를 따릅니다.

📅 시험 기본 정보

🗓️ 시험 시간표

같은 교시에 여러 선택과목이 있으면 /로 구분해 입력하세요. (예: 기하 / 영어권 문화)

🧭 학년별 이동 방식

학년마다 이동 교실과 대상을 정합니다. 앞·뒷번호부터 인원만 넣거나, 시작 번호부터 N명, 번호 범위를 직접 지정할 수 있습니다. 결번은 건너뛰고 목표 인원만큼 선택합니다.

🪑 좌석 배치 기본값

교실(반): 본반·이동반 열을 나누어 배치하며, 좌석번호는 각각 1번부터 (열 단위 위→아래)

🏛️ 고사실 목록

📤 학생업로드

나이스 학생편성현황을 업로드하고 수강 과목을 확인합니다.

📤 나이스 학생편성현황 업로드

나이스에서 다운로드한 학생편성현황 엑셀 파일을 학년별로 업로드하세요. 파일은 브라우저에서만 파싱됩니다.

다운로드 경로: 나이스 → 시간표 → 편제및과목개설관리 → 수강생편성 → 학년설정 후 조회 → 학생편성현황 → 엑셀출력 → 엑셀파일 다운로드

성명 앞에 (미재학)이 붙은 학생은 현재 재학생이 아니므로 자동 제외됩니다.

👥 학생별 수강 과목

업로드된 학생 명렬입니다. 행 끝 휴지통 버튼으로 개별 학생을 삭제할 수 있습니다.

📚 과목별 수강 현황

🏫 시험실배정

시험 일정을 생성하고 교실·좌석 배치를 확인합니다.

⚙️ 시험 일정 생성

Step 1 시험 시간표와 Step 2 학생 데이터를 연결하여 학생별 시험 일정과 과목별 응시자 목록을 생성합니다.

📝 교시별 과목 응시자

요약만 표시합니다. 학생별 좌석·고사실은 아래 교실 배치와 자료검증에서 확인하세요.

🏫 교실별 배치 현황

반=교실 원칙으로 본 반 학생(이동 제외)과 이동반 유입 학생이 자동 계산됩니다. 과목별 고사실 수동 배정은 필요 없습니다.

🪑 고정 좌석 부여

각 교실에 배치된 학생(본 반·이동반)에게 좌석을 1회 부여합니다. 시험 일정 생성·페이지 불러오기 시 자동 배정되며, 필요할 때만 아래 버튼으로 재배정하세요.

✅ 자료검증

시험실·좌석번호를 최종 확인하고 수정합니다. 변경 사항은 출력물에 반영됩니다.

📋 시험실·좌석 확인

교실별로 배치를 검토하고 일괄 변경할 수 있습니다.

🪑 좌석배치도

교실별 고정 좌석 배치를 출력합니다. 칠판 부착용(교탁·앞쪽 상단)과 교탁 부착용(감독관 시점, 상하·좌우 반전) 중 선택할 수 있습니다.

📋 결시현황표

교실·일차별 통합 응시현황표 (학급 구분, 교시별 응시현황)를 출력합니다.

📌 선택과목 응시 학생

고사실별·학년별·일차·교시·과목별 선택과목 응시 학생 명단 — 이동 학생이 있는 고사실은 학년마다 별도 표 (B4 가로, 교실 부착용)

📅 학생 개인별 시험시간표

학급별 개인별 시험 시간표 게시용 — 해당 반 학생 전원(번호순), 일차·교시별 과목 (이동/고정 구분, B4 가로, 학급 게시용)

🏫 시험실배정현황

학급별 시험실 배정을 출력합니다.
